# Manual shell CSS (WS1)

Stable class names for parallel workstreams. Ported from Libretto `styles.css`.

| Class | Role |
|-------|------|
| `manual-shell` | Root wrapper on Standard/Full guides |
| `sidebar` / `sidebar.open` | Persistent TOC + mobile drawer |
| `sheet` | Main reading column |
| `nav-part` / `nav-link` | Roman parts + chapter links |
| `contents-row` | Editorial contents grid rows |
| `chapter-head` / `chapter` / `prose` | Chapter chrome + body |
| `ruler` / `ruler-readout` | Fixed scroll ruler (chapter routes) |
| `pager` | Prev/next chapter navigation |
| `foot-frieze` | SVG `NouveauFrieze` footer mount |
| `architecture-plate-frame` | `NouveauFrame` wrapper for architecture blocks |

Lite guides keep the legacy top `topbar` layout only.
