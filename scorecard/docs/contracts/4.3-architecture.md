# §4.3 Interactive architecture plate

## File

`content/architecture.json` → `ArchitectureFile`

## Fields

| Field | Notes |
|-------|--------|
| `figureId` | Default `ARCH_001`; pattern `ARCH_###` |
| `layout` | `spine-lr` \| `layered` \| `radial` — layout engine may set `x`/`y` on nodes |
| `nodes[]` | `id`, `label`, optional `path`, `group`, `tone`, `detail`, coordinates |
| `detail` | `role`, `evidence`, `ports[]`, `summary` — shown in detail rail (WS3) |
| `groups[]` | Optional group metadata referenced by `node.group` |
| `edges[]` | `from`, `to`, optional `label` |
| `mermaid` | Export/print fallback only — not primary UI |

## Interactive v1 (WS3)

- Click/double-tap selects a node; detail rail shows `detail`.
- Subtle motion on active node unless `prefers-reduced-motion`.
- Generated Standard/Full sites: ≥3 nodes, ≥2 edges (`validateArchitecture` options).

## Validation

`validateArchitecture(file, exists, { minNodes?, minEdges?, requireInteractiveFields? })`
