# §4.6 Media and live blocks (no iframe v1)

All blocks extend provenance fields (`provenance`, `source`, optional `evidence`). **No `<iframe>`** in v1 — framed screenshots and clips only; optional `linkOut` opens deploy URL in a new tab.

## Block types

| `type` | TS type | Required media |
|--------|---------|----------------|
| `live` | `LiveBlock` | `mode`: `screenshot` \| `clip`; `src` and/or `webm`/`gif`; optional `chrome`, `poster`, `caption` |
| `shot` | `ShotBlock` | `src` |
| `motion` | `MotionBlock` | `gif` + `poster`; optional `webm` |
| `desk` | `DeskBlock` | `kind` (e.g. `nouveau` for generic ornament desk, §5.6) |
| `figure` | `FigureBlock` | `id` (e.g. `FIG_001` or architecture ref) |

Legacy `live.url` is accepted; validators treat it as `linkOut`/`screenshot` fallback.

## Chrome

`MediaChrome`: `{ routeLabel?, tabs?[] }` — Libretto-style frame labels (WS4 renderer).

## Validation

`validateManualBlock(block, path?)` — called from `validateManual` per chapter.
