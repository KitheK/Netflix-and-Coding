# §4.4 Font pack manifest

**WS5 contract extension (PR #5 follow-up):** optional `defaultFaceIds`, `substitutions`, `proprietarySlots` on manifests; optional `theme.fontRoles` overrides per role using catalog `FontFaceId` values.

## Files

| Path | Role |
|------|------|
| `content/font-pack.json` | Active pack in a scaffolded project (optional) |
| `font-packs/<packId>/manifest.json` | Traced or built-in pack directory |
| `public/fonts/catalog.json` | Web paths for bundled `FontFaceId` faces (check validation) |

Type: `FontPackManifest`

Built-in ids: `libretto-default`, `editorial-plain`, `making-software`, `custom`.

`theme.json`:

- `fontPackId` — pack preset
- `fontRoles?: { display?, body?, ui?, mono? }` — per-role overrides (`FontFaceId`)
- legacy `fonts` enums — Paléologue variant toggles for `libretto-default`

## Validation

- `validateFontPackManifest(manifest, exists?)` — when `exists` is provided, each `faces.*.woff2` path must resolve.
- `validateTheme` — unknown `fontRoles.*` ids error.
- `scorecard-kit check` — resolves active pack + `fontRoles` against `public/fonts/catalog.json`.
