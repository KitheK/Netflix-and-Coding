# §4.2 Product naming

## Rules

1. `manual.projectName` — required on **generate** (pixel wordmark + Paléologue pairing, §5.4).
2. `manual.title` — always ``${projectName} Guide`` (constant `MANUAL_TITLE_SUFFIX`).
3. `scorecard.projectName` — optional duplicate for summary hero copy.
4. Platform string — `PLATFORM_ATTRIBUTION` (`Made with Scorecard`) in footer/mono only; never the hero `h1`.

## Helpers

```ts
manualTitleFromProjectName("Conductor"); // "Conductor Guide"
validateManual(manual, { requireProjectName: true });
```

Existing kit content may omit `projectName` until WS4/WS2 backfill; validators only enforce the title pairing when `projectName` is present.
