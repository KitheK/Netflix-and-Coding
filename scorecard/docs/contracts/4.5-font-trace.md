# §4.5 Font trace pack layout

On-disk layout for a user-owned or PD reference sheet:

```
font-packs/
  <packId>/
    manifest.json       # FontPackManifest (§4.4)
    reference.png       # optional user sheet (may be gitignored)
    source/             # intermediate SVG or glyphs JSON
    *.woff2
    LICENSE
```

## Types

- `FONT_PACK_DIR_LAYOUT` — relative filenames
- `fontTracePackPaths(packId, rootDir?)` → `FontTracePackPaths`
- `validateFontTracePack(paths, exists)` — manifest, license, and at least one WOFF2

CLI `npx scorecard-kit fonts trace` (WS5) writes this tree; WS0 defines paths and validation only.
