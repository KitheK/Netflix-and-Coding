# Profiles → modules

| Module | When |
|--------|------|
| Scorecard + Run + Built vs borrowed | Always |
| Architecture | ≥3 components or opt-in |
| APIs | Exposes/consumes external APIs/models/datasets |
| Timeline | History milestones; else build-log / hourly |
| Decisions | ≥1 captured |
| Requirements map | Coursework or author supplies spec |
| Team | Team profile (opt-in else) |
| Live demo | URL/build exists |
| Research | Research profile |
| Install / public API | OSS profile |

## Size heuristics

- Lite: day / hackathon / few files
- Standard: weeks, multiple components
- Full: months+, merges, many services — confirm with A5/A6
